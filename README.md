# Samvidhan Quest

A React + Vite gamified learning platform for the Indian Constitution.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` checks the app files.

## Notes

This project uses React, Tailwind CSS, Framer Motion, Lucide Icons, html2canvas, and browser localStorage. It does not use a backend, authentication, or account links.
